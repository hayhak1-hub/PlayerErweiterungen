# Player Browser

Das Zusatzpaket „Player Browser“ für den Allclearworld Player: ein Browser auf dem Kern von Firefox (GeckoView) mit
echten Firefox-Erweiterungen.

Die Datei `player-browser.acwb` unter „Releases“ ist **kein installierbares Paket**. Sie ist versiegelt und lässt sich
für sich allein weder installieren noch starten. Der Allclearworld Player lädt sie, öffnet sie und übergibt das Paket
Android zum Installieren.

*The file `player-browser.acwb` under "Releases" is not an installable package. It is sealed; only the Allclearworld
Player can open and install it.*
